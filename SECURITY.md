# Research package scope

This repository contains research code, recorded weather observations and synthetic engineering
examples. The execution component accepts an injected transport; its examples supply an in-memory
transport and no venue adapter or signing credentials. The optional connection probe makes read-only
HTTPS GET requests only when a URL is explicitly supplied.

Do not submit credentials, account-linked logs or private infrastructure information in issues.

The MIT license applies to the authored code and documentation. It does not assert ownership of
third-party observations or forecast products. See `data/README.md` for the example's provenance.
