# Reproducibility

From the repository root, install `requirements.txt` and run `python -B replay.py --out output/replay.png`.
This reads the three included journals and produces the posterior/distribution plot and hourly
maximum-per-bucket consistency residuals. The original full calibration and event-study estimates
are not regenerated by that command. Python 3.11 was used for the publication functionality check.

Data provenance and file hashes are in `data/manifest.json`. Identical inputs support an exact input
comparison; numerical results may depend on model sampling and dependency versions. Compare event
counts and numerical tolerance rather than assuming image-byte identity across plotting versions.
