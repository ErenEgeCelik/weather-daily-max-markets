# Synthetic acquisition fixtures

These four payloads are hand-authored examples, not recorded market observations.
`LTZZ` is an illustrative station identifier. The sequence crosses a UTC month
boundary, repeats one official report through two sources, introduces a corrected
report at the same observation time, and then advances to a new report.

The MGM decimal temperature deliberately differs from the official METAR integer.
The walkthrough supplies arrival times separately; none of these timings measures
historical source performance or a trading advantage.
